# Vídeo institucional ON Engenharia (Remotion)

Vídeo de 96 s em 1920×1080, baseado no portfólio
(onengenharia.github.io/onengenharia-painel/portfolio.html).

- Pré-visualizar e editar: `npm run dev` (abre o Remotion Studio)
- Renderizar: `npx remotion render Portfolio out/portfolio-on-engenharia.mp4`

As cenas ficam em `src/Scenes.tsx`, a ordem e a duração em `src/Portfolio.tsx`,
e as fotos e logos em `public/`.
